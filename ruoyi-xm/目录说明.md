# 项目目录说明

本文用于快速说明当前 `ruoyi-xm` 目录下各模块的职责、现状与维护边界。

## 一级目录

| 目录 | 类型 | 当前职责 | 后续方向 |
|------|------|----------|----------|
| `wx_app` | 小程序前端主目录 | 同时承载 C 端页面与商家端页面。 | 继续补齐真实登录、订单、支付、核销、营销与结算能力。 |
| `ruoyi-vue-wxmini-main` | 后端 + 运营后台 | Spring Boot 后端、Maven 多模块、RuoYi 运营后台、商城领域模块、SQL 与项目文档。 | 继续补齐真实 API、支付退款分账、租户隔离、定时任务与数据分析。 |
| `merchant_images` | 本地图片资源 | 按商家 ID 存放头像、门店图、Banner、商品图。 | 与统一上传接口、对象存储或静态资源服务对齐。 |
| `shanchu` | 已删除文件归档说明 | 存放已删资料的索引说明。 | 仅做历史参考，不作为现行设计文档。 |
| `.vscode` / `.idea` | IDE 配置 | 本地开发工具配置。 | 不承载业务逻辑。 |

## `wx_app` 目录

`wx_app` 是当前唯一维护中的小程序前端目录。

历史上的独立 `merchant_app` 已并入这里，不再单独维护。

| 子目录/文件 | 说明 |
|-------------|------|
| `app.js` | 小程序全局配置、基础地址、全局登录态与公共方法。 |
| `app.json` | 页面路由、窗口、权限、TabBar 配置。当前同时注册 C 端页面与商家端页面。 |
| `api` | 接口封装。C 端接口位于常规模块，商家端接口位于 `api/merchant-mini/*`。 |
| `pages` | 页面目录。C 端页面位于 `pages/*`，商家端页面位于 `pages/merchant/*`。 |
| `components` | 公共组件，包括空状态、商品卡、订单卡、二维码等。 |
| `services` | 前端业务服务，目前主要是购物车和模板配置服务。 |
| `utils` | 公共请求与工具函数；商家端专用能力位于 `merchant-request.js`、`merchant-util.js`。 |
| `assets` | 小程序静态资源。 |
| `data` | 本地演示/降级数据。后续应逐步减少业务依赖。 |

## 当前前端边界

### C 端

- 页面路径：`wx_app/pages/*`
- 主要能力：浏览商家、商品详情、购物车、下单、订单、评价、收藏
- 鉴权：`Wx-Authorization: {token}`

### 商家端

- 页面路径：`wx_app/pages/merchant/*`
- 接口模块：`wx_app/api/merchant-mini/*`
- 工具模块：`wx_app/utils/merchant-request.js`、`wx_app/utils/merchant-util.js`
- 鉴权：`Wx-Authorization: Bearer {token}`

## 后端领域模块状态

| 模块 | 当前状态 |
|------|----------|
| `ruoyi-mall-common` | 已具备微信 JWT、上下文、支付抽象等公共能力。 |
| `ruoyi-mall-user` | 已具备微信登录、用户信息和部分用户域基础能力。 |
| `ruoyi-mall-merchant` | 已具备商家、门店、商家用户、审核等后台管理基础。 |
| `ruoyi-mall-product` | 已具备商品、分类、团购活动模型和后台接口。 |
| `ruoyi-mall-order` | 已具备订单、订单项、退款记录和后台订单/售后接口。 |
| `ruoyi-mall-finance` | 已具备流水、分账、提现和财务统计基础。 |
| `ruoyi-mall-marketing` | 当前偏预留，已有 Banner、Coupon 实体，业务层需继续补齐。 |
| `ruoyi-mall-pay` | 当前为基础实现，支付下单、查询、回调仍需完善真实逻辑。 |
| `ruoyi-wxmini` | 已承载 C 端和商家端入口接口，是小程序 API 网关层。 |

## 维护规则

1. 以后新增商家端页面，统一放到 `wx_app/pages/merchant/*`。
2. 以后新增商家端接口封装，统一放到 `wx_app/api/merchant-mini/*`。
3. 新文档不再把 `merchant_app` 当成现行代码目录。
4. 历史文档里出现 `merchant_app` 时，默认表示旧目录名或迁移前状态。
