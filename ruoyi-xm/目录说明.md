# 项目目录说明

本文用于快速说明 `E:\ruoyi\ruoyi-xm` 下各目录的职责、当前状态和后续建设方向。

## 一级目录

| 目录 | 类型 | 当前职责 | 后续方向 |
|------|------|----------|----------|
| `wx_app` | C 端微信小程序 | 消费者浏览商家/商品、购物车、下单、支付、订单、核销码、收藏、优惠券、评价。 | 接入真实微信登录、支付、优惠券、评价、收藏、售后和模板配置。 |
| `merchant_app` | 商家端微信小程序 | 商家员工登录、工作台、订单处理、扫码核销、商品管理、门店设置、员工权限、财务、营销、入驻申请。 | 完成真实接口联调、商家权限隔离、多门店、退款审核、营销活动和提现。 |
| `ruoyi-vue-wxmini-main` | 后端 + 运营后台 | Spring Boot 后端、Maven 多模块、RuoYi 运营后台、商城领域模块、SQL 和项目文档。 | 继续补齐支付、营销、租户隔离、后台真实 API、定时任务和数据分析。 |
| `merchant_images` | 本地图片资源 | 按商家 ID 存放头像、门店图、Banner、商品图。 | 与统一上传接口、对象存储或静态资源服务对齐。 |
| `.vscode` / `.idea` | IDE 配置 | 本地开发工具配置。 | 不承载业务逻辑。 |

| `assets` | 小程序静态图片资源。 |
| `README.md` | C 端接口对接与页面说明。 |

## SaaS 多端建设重点

1. 所有商家侧数据必须围绕 `merchantId` 做隔离。
2. 多门店能力必须围绕 `storeId` 继续补齐。
3. 商家员工接口必须基于 `staffId + permissionCodes` 做权限控制。
4. C 端模板配置应支持平台默认、商家覆盖、门店扩展。
5. 支付、退款、提现、分账必须和订单状态机、财务流水联动。
6. 运营后台应逐步替换 mock 数据，统一接入真实 `mall-*` 后端接口。
