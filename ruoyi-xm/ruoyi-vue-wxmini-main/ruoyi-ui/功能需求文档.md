# 零点科技团购商城运营后台 - 功能需求文档

> 版本：v1.0
> 日期：2026-05-09
> 技术栈：Vue 2.6 + Element UI 2.15 + ECharts 5.4 + Vuex + Vue Router

---

## 一、系统概述

本系统为团购商城的数据运营后台管理平台，面向平台运营人员，提供商家管理、订单管理、财务管理、数据分析等核心功能模块。

### 1.1 整体架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Vue 2.6 | SPA单页应用 |
| UI组件库 | Element UI 2.15 | 表格、表单、弹窗、分页等 |
| 图表库 | ECharts 5.4 | 折线图、柱状图、饼图等数据可视化 |
| 状态管理 | Vuex | 用户信息、权限、菜单路由 |
| 路由 | Vue Router 3.x | 静态路由，本地菜单配置 |
| HTTP | Axios | 后端API通信（当前为mock模式） |

### 1.2 菜单结构（6大模块）

```
├── 首页（数据运营大屏）
├── 数据中心
│   ├── 平台概览
```

## 二、首页 - 数据运营大屏

**路由**: `/index`

### 2.1 功能描述

首页为数据运营大屏，展示平台核心运营数据概览，供运营人员快速了解平台状态。

### 2.2 页面元素

| 区域 | 元素 | 数据来源 | 说明 |
|------|------|----------|------|
| 指标卡片行 | 今日订单数 | API: getDashboardStats | 数字动画展示 |
| | 今日营收(元) | API: getDashboardStats | 金额格式化 |
| | 入驻商家数 | API: getDashboardStats | 数字动画展示 |
| 订单趋势 | ECharts折线图 | API: getTrendData | 近7天订单数/成交数双线 |
| 营收趋势 | ECharts柱状图 | API: getTrendData | 近7天营收渐变柱状 |
| 订单状态分布 | ECharts环形饼图 | API: getDashboardStats | 待支付/已支付/已完成/已取消 |
| 热销商品TOP5 | el-table | API: getDashboardStats | 排名徽章+商品名+销量+营收 |
| 快捷入口 | 4个操作卡片 | 路由跳转 | 用户/订单/商家/数据统计 |

### 2.3 接口定义

```
GET /api/data/dashboard-stats   → { todayAmount, totalFlow, todayOrders, merchantCount, userTotal, userTodayNew }
GET /api/data/trend-data        → { dates:[], orderCounts:[], amounts:[], completedCounts:[] }
```

## 四、商家中心

### 4.1 商家列表

**路由**: `/merchant/list`

**搜索条件**:
| 字段 | 类型 | 说明 |
|------|------|------|
| 商家名称 | input | 模糊搜索 |
| 商家等级 | select | S/A/B/C |
| 状态 | select | 正常/禁用/待审核 |

**表格字段**:
| 列名 | 字段 | 说明 |
|------|------|------|
| ID | id | 主键 |
| 商家名称 | name | - |
| 联系人 | contact | - |
| 联系电话 | phone | - |
| 等级 | level | 标签：S-红色/A-橙色/B-默认/C-灰色 |
| 状态 | status | 标签：1正常-绿色/0禁用-灰色/2待审核-橙色 |
| 商品数 | products | - |
| 月销售额 | monthlySales | 金额格式 |
| 入驻时间 | createTime | - |
| 操作 | - | 查看详情、审核（待审核状态显示） |

**操作**:
- **查看详情**: 跳转 `/merchant/detail/:id`
- **审核**: 弹窗，支持通过/拒绝，拒绝需填写原因

**接口**:
```
GET  /api/merchant/list        → { list:[], total, pageNum, pageSize }
POST /api/merchant/audit/:id   → { code:200 }
```

### 4.2 商家详情

**路由**: `/merchant/detail/:id`（隐藏路由，从列表页进入）

**页面结构**:
- 顶部：返回按钮
- 基本信息：el-descriptions 展示商家名称、联系人、电话、等级(tag)、状态(tag)、入驻时间、商品数、月销售额
- el-tabs 标签页：
  - 基本信息（详细字段）
  - 商品列表（待开发）
  - 订单记录（待开发）
  - 流水记录（待开发）

**接口**:
```
GET /api/merchant/detail/:id → 商家完整信息
```

### 4.3 商家等级

**路由**: `/merchant/level`

**表格字段**: 等级名称、佣金比例(%)、描述、商家数量、操作(编辑)

**操作**:
- **编辑**: 弹窗表单，字段：等级名称、佣金比例(el-input-number)、描述(el-textarea)

**接口**:
```
GET  /api/merchant/levels      → [{ id, name, commission, description, merchantCount }]
PUT  /api/merchant/level/:id   → { code:200 }
```

### 4.4 商家流水

**路由**: `/merchant/flow`

**搜索条件**: 商家名称、类型(订单收入/提现扣款/退款扣款)、时间范围(date-picker)

**表格字段**:
| 列名 | 字段 | 说明 |
|------|------|------|
| 商家名称 | merchantName | - |
| 类型 | type | 标签：收入-绿色/提现-橙色/退款-红色 |
| 金额 | amount | 正数绿色+号，负数红色-号 |
| 关联订单号 | orderId | - |
| 时间 | time | - |

**接口**:
```
GET /api/merchant/flow → { list:[], total }
```

### 4.5 提现管理

**路由**: `/merchant/withdraw`

**搜索条件**: 商家名称、状态(待审核/已审核/已完成/已拒绝)

**表格字段**: 商家名称、提现金额、银行名称、银行账号(脱敏)、申请时间、状态(tag)、操作

**状态说明**:
| 值 | 文本 | 标签颜色 |
|----|------|----------|
| 0 | 待审核 | 橙色 |
| 1 | 已审核 | 蓝色 |
| 2 | 已完成 | 绿色 |
| 3 | 已拒绝 | 红色 |

**操作**:
- 待审核：通过(confirm确认)、拒绝(弹窗填写原因)
- 其他状态：查看详情(弹窗)

**接口**:
```
GET  /api/merchant/withdraw        → { list:[], total }
POST /api/merchant/withdraw/approve/:id → { code:200 }
POST /api/merchant/withdraw/reject/:id  → { code:200 }
```

| 值 | 标签颜色 | 说明 |
|----|----------|------|
| S | 红色(danger) | 顶级商家 |
| A | 橙色(warning) | 优质商家 |
| B | 蓝色(primary) | 普通商家 |
| C | 灰色(info) | 新入驻商家 |
