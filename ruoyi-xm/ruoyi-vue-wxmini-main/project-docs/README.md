## 数据库脚本

### 业务表SQL（修正版，可直接执行）

SQL脚本位于 `project-docs/test-sql/` 目录：

| 文件 | 说明 |
|------|------|
| 01_create_tables.sql | 15张业务表建表脚本（含补建的mall_login_log和mall_oper_log） |
| 02_init_data.sql | 商家等级、用户、登录日志、操作日志基础数据 |

执行顺序：`01 → 02`

> 数据库统一使用 `ruoyi-cs`，已修复原始SQL中的表名/列名不一致问题。

### 原始SQL（仅供参考）

原始SQL位于 `ruoyi-ui/sql/` 目录，存在问题请勿直接执行：

| 文件 | 说明 | 问题 |
|------|------|------|
| 01_create_tables.sql | 12张业务表建表脚本 | 缺少mall_login_log和mall_oper_log的DDL |
| 02_init_data.sql | 初始化数据 | 表名mall_merchant_level与DDL的merchant_level不一致，列名level_name与name不一致 |
| 03_merchant_product_data.sql | 4个商家+14个商品数据 | 待验证 |
| 04_order_flow_data.sql | 2周订单/流水/售后/提现/分账数据 | 待验证 |
