## 当前系统范围

系统按四个端/层协作：

- C 端小程序 `wx_app`：消费者前台交易闭环。
- 商家端小程序 `merchant_app`：商家经营和履约工具。
- 运营后台 `ruoyi-ui`：平台运营、审核、监管、财务和数据分析。
- 后端服务 `ruoyi-admin` + `ruoyi-mall-*` + `ruoyi-wxmini`：统一 API、鉴权、领域服务和微信能力。

## 文档维护规则

- 顶层定位以“完整 SaaS 多端商家系统”为准。
- 端侧说明必须明确调用方、API 前缀、鉴权方式和当前实现状态。
- 模块说明必须区分“已实现”“基础实现”“预留/待实现”。
- 接口文档应同步标注 C 端、商家端、运营后台三类调用方。
- 涉及 SaaS 隔离的数据结构必须说明 `merchantId`、`storeId`、`userId`、`staffId` 等归属字段。
