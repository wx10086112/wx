## 一、项目整体架构

### 1.1 Maven模块依赖关系

```
ruoyi (parent POM)
  ├── ruoyi-common        ← 公共工具/实体/注解/常量/过滤器
  ├── ruoyi-system        ← 系统服务/Mapper/Domain（含wxmini数据层）
  ├── ruoyi-quartz        ← 定时任务
  ├── ruoyi-generator     ← 代码生成器
  ├── ruoyi-framework     ← 安全框架/配置/拦截器/登录注册
  ├── ruoyi-wxmini        ← 微信小程序专用模块
  └── ruoyi-admin         ← 启动入口/控制器层（聚合所有模块）
```

### 1.2 核心第三方依赖

| 依赖 | 版本 | 用途 |
|------|------|------|
| weixin-java-miniapp | 4.7.0 | 微信小程序SDK |
| wx-java-pay-spring-boot-starter | 4.7.0 | 微信支付V3 |
| hutool-all | 5.8.20 | 小程序JWT工具 |
| jjwt | 0.9.1 | 后台JWT认证 |
| druid | 1.2.23 | 数据库连接池 |
| fastjson2 | 2.0.53 | JSON序列化 |
| pagehelper | 1.4.7 | MyBatis分页 |
| spring-boot-starter-security | 5.7.12 | 安全框架 |
| velocity-engine-core | 2.3 | 代码生成模板 |

### 1.3 双认证模型

| 维度 | 后台管理端 | 微信小程序端 |
|------|-----------|-------------|
| 认证方式 | Spring Security + JWT (jjwt) | 自定义WxMiniJwtFilter + Hutool JWT |
| Token头 | `Authorization: Bearer {token}` | `Wx-Authorization: Bearer {token}` |
| 过滤器 | JwtAuthenticationTokenFilter | WxMiniJwtFilter |
| 白名单 | /login, /register, /captchaImage | /wxmini/login, /wxmini/portal/**, /wxmini/pay/notify |
| 存储 | Redis (LOGIN_TOKEN_KEY) | 无状态（签名验证） |

## 四、ruoyi-framework 框架模块

### 4.1 包结构

| 包路径 | 说明 | 主要类 |
|--------|------|--------|
| `.aspectj` | 切面 | DataScopeAspect, DataSourceAspect, LogAspect, RateLimiterAspect |
| `.config` | 配置类 | SecurityConfig, DruidConfig, RedisConfig, ResourcesConfig, FilterConfig等 |
| `.config.properties` | 配置属性 | DruidProperties, PermitAllUrlProperties |
| `.datasource` | 动态数据源 | DynamicDataSource, DynamicDataSourceContextHolder |
| `.interceptor` | 拦截器 | RepeatSubmitInterceptor |
| `.manager` | 管理器 | AsyncManager, ShutdownManager |
| `.security` | 安全相关 | JwtAuthenticationTokenFilter, AuthenticationEntryPointImpl, LogoutSuccessHandlerImpl |
| `.web.exception` | 全局异常 | GlobalExceptionHandler |
| `.web.service` | 框架服务 | SysLoginService, SysRegisterService, TokenService, SysPasswordService等 |

### 4.2 核心配置类

#### SecurityConfig（安全配置）
- 启用 `@EnableMethodSecurity`
- CSRF禁用，Session无状态
- 匿名访问：`/login`, `/register`, `/captchaImage`, `/wxmini/**`, Swagger, 静态资源
- 添加 `JwtAuthenticationTokenFilter` 在 `UsernamePasswordAuthenticationFilter` 之前
- 添加 `CorsFilter` 跨域过滤器

#### FilterConfig（过滤器配置）
- XssFilter（可选，xss.enabled=true时启用）
- RepeatableFilter（/*路径，防重复请求）

#### ResourcesConfig（资源配置）
- 静态资源映射：`/profile/**` → 上传文件目录
- 注册 `RepeatSubmitInterceptor` 拦截器
- CORS跨域配置

### 4.3 核心服务类

#### SysLoginService（登录服务）
| 方法 | 参数 | 说明 |
|------|------|------|
| login | String username, String password, String code, String uuid | 登录验证（验证码→预检→认证→记录→返回token） |

#### SysRegisterService（注册服务）
| 方法 | 参数 | 说明 |
|------|------|------|
| register | RegisterBody | 用户注册（验证码→唯一性校验→加密→插入） |

#### TokenService（Token服务）
| 方法 | 参数 | 说明 |
|------|------|------|
| createToken | LoginUser | 创建JWT并存入Redis |
| getToken | HttpServletRequest | 从请求头获取token |
| getLoginUser | HttpServletRequest | 获取登录用户信息 |
| verifyToken | LoginUser | 验证token有效性 |
| refreshToken | LoginUser | 刷新token有效期 |
| delLoginUser | String | 删除Redis中的token |

#### JwtAuthenticationTokenFilter（JWT认证过滤器）
- 继承 `OncePerRequestFilter`
- 从请求头 `Authorization` 提取JWT
- 通过 `TokenService` 验证Token
- 设置 `SecurityContextHolder` 认证信息

## 九、安全模型详解

### 9.1 后台管理端认证流程

```
用户登录 → SysLoginController.login()
  → SysLoginService.login()
    → 验证码校验 (Redis)
    → 登录预检 (IP黑名单/密码长度)
    → AuthenticationManager.authenticate()
    → 记录登录日志
    → TokenService.createToken(LoginUser)
      → JWT生成 (jjwt)
      → Redis存储 (LOGIN_TOKEN_KEY)
  → 返回token

后续请求 → JwtAuthenticationTokenFilter
  → 从Authorization头提取token
  → TokenService.getLoginUser()
  → SecurityContextHolder设置认证
  → 放行
```

### 9.2 微信小程序端认证流程

```
小程序登录 → WxLoginController.login(appid, code)
  → wxMaService.getUserService().getSessionInfo(code)
  → 获取openId
  → 查询/注册user_info
  → IWxMiniJwtService.createToken(userId)
    → Hutool JWTUtil.sign()生成token
  → 返回WxUserInfo + apiToken

后续请求 → WxMiniJwtFilter
  → 从Wx-Authorization头提取token
  → IWxMiniJwtService.verifyToken()
  → WxMiniUserContext.setCurrentUserId()
  → 放行
  → finally: WxMiniUserContext.clear()
```

### 9.3 Spring Security白名单

```java
.antMatchers("/login").permitAll()
.antMatchers("/register").permitAll()
.antMatchers("/captchaImage").permitAll()
.antMatchers("/wxmini/**").permitAll()     // 微信小程序全部放行
.antMatchers("/common/download**").permitAll()
// Swagger, 静态资源等...
```
