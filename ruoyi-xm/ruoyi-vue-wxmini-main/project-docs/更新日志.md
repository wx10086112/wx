## 2026-05-12 前端字段名修复: res.data → res + 模板字段名适配

### 变更概要
- 修复所有商城页面的响应数据解析：`res.data.list` → `res.rows`，`res.data.total` → `res.total`
- 修复 Dashboard 首页字段名适配（`todayAmount` → `todayRevenue` 等）
- 修复商家列表页模板字段名：`products` → `productCount`，`monthlySales` → `totalIncome`

### 问题根因

RuoYi 响应拦截器（`request.js`）返回 `res.data`（即 JSON body），所以页面拿到的 `res` 直接是 `{ code: 200, rows: [...], total: N }`，不需要再 `.data`。

- `TableDataInfo` 返回字段：`rows`（不是 `list`）
- `AjaxResult.success(data)` 返回字段：`data`
- 详情页用 `res.data` 正确（取 AjaxResult 的 data 字段）
- 列表页用 `res.rows` + `res.total`（取 TableDataInfo 的字段）

### 文件变更

| 文件 | 操作 | 说明 |
|------|------|------|
| `ruoyi-ui/src/views/merchant/*.vue` (7个) | 修改 | res.data.list→res.rows, res.data.total→res.total |
| `ruoyi-ui/src/views/order/*.vue` (4个) | 修改 | 同上 |
| `ruoyi-ui/src/views/finance/*.vue` (4个) | 修改 | 同上 |
| `ruoyi-ui/src/views/ops-log/*.vue` (2个) | 修改 | 同上 |
| `ruoyi-ui/src/views/tool/gen/editTable.vue` | 修改 | 同上 |
| `ruoyi-ui/src/views/merchant/list.vue` | 修改 | products→productCount, monthlySales→totalIncome |
