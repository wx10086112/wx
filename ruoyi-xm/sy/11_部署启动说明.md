# 11 部署启动说明

---

## 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| JDK | 8+ | |
| Maven | 3.6+ | |
| MySQL | 8.0+ | |
| Redis | 6.0+ | |
| Node.js | 14+ | 仅运营后台前端需要 |

## 配置位置

| 配置项 | 位置 | 说明 |
|--------|------|------|
| 数据库连接 | `application.yml` → `spring.datasource` | 需配置 URL/用户名/密码 |
| Redis 连接 | `application.yml` → `spring.redis` | 需配置 host/port/密码 |
| 文件上传路径 | `application.yml` → `ruoyi.profile` | Windows示例:`D:/ruoyi/uploadPath` |
| JWT 密钥 | `application.yml` → `token.secret` | 至少32位随机字符串 |
| 微信小程序配置 | `application.yml` → `wx.miniapp.configs` | AppID/Secret |
| 微信支付配置 | `application.yml` → `wx.pay` | 商户号/V3密钥/证书路径 |
| 支付 Stub 开关 | `application.yml` → `wx.pay.stub-enabled` | 开发环境=true，生产=false |

## 启动步骤

### 1. 初始化数据库

```sql
-- 执行一键建库脚本
source E:\ruoyi\ruoyi-xm\ruoyi-vue-wxmini-main\project-docs\test-sql\all_in_one.sql

-- 如需追加结算相关表
source E:\ruoyi\ruoyi-xm\ruoyi-vue-wxmini-main\project-docs\test-sql\15_merchant_settlement_record.sql
```

### 2. 启动后端

```bash
cd E:\ruoyi\ruoyi-xm\ruoyi-vue-wxmini-main
mvn clean install -DskipTests
mvn spring-boot:run -pl ruoyi-admin
```

### 3. 启动运营后台前端

```bash
cd E:\ruoyi\ruoyi-xm\ruoyi-vue-wxmini-main\ruoyi-ui
npm install
npm run dev
```

### 4. 启动小程序

使用微信开发者工具分别打开：
- `E:\ruoyi\ruoyi-xm\wx_app`（C端）
- `E:\ruoyi\ruoyi-xm\merchant_app`（商家端）
