## 三、失败项详情

### Failed-1：测试18 支付 Stub 无环境隔离

| 项目 | 内容 |
|------|------|
| **测试编号** | 测试18 |
| **预期** | dev 外不能暴露 stub 参数 |
| **实际代码** | `WxPayController.java:59` — `if (stubEnabled)` 仅靠配置开关 |
| **问题** | 生产误配置 `stub-enabled=true` 就返回伪造支付参数 |
| **代码位置** | `ruoyi-wxmini/.../controller/WxPayController.java` 第 59-67 行 |
| **修复思路** | 加 `@Profile("dev")` 或 `@ConditionalOnProperty(value="wx.pay.stub-enabled", havingValue="true", matchIfMissing=false)` |

### Failed-2：测试19 前端路由/按钮无权限控制

| 项目 | 内容 |
|------|------|
| **测试编号** | 测试19 |
| **预期** | 分销商看不到系统管理、分销商管理等 |
| **实际代码** | `ruoyi-ui/src/router/index.js` — 业务菜单在 constantRoutes 无 permissions |
| **问题** | 依赖后端菜单树，前端无二次拦截 |
| **代码位置** | `ruoyi-ui/src/router/index.js` 第 90-180 行 |
| **修复思路** | meta 加 permissions 字段 + 按钮加 v-hasPermi 指令 |

### Failed-3：测试20 金额单位部分不一致

| 项目 | 内容 |
|------|------|
| **测试编号** | 测试20 |
| **预期** | 同一业务不差 100 倍 |
| **实际代码** | 商家端 `merchant_app/utils/util.js:56` formatPrice 除以100；后端 `MerchantMiniServiceImpl` 部分返回 DECIMAL 元 |
| **问题** | 前后端金额单位约定不一致 |
| **代码位置** | `merchant_app/utils/util.js:56`, `MerchantMiniServiceImpl.java` getSettlementOverview |
| **修复思路** | 统一约定：后端返回分，前端直接显示；或后端返回元，前端不除以100 |
