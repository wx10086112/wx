# 03 后台操作手册

> 写给平台运营人员的使用指南。

---

## 1. 创建分销商

```
路径：分销商管理 → 新增分销商
填写：
  - 分销商名称（如"华东区代理"）
  - 联系人、联系电话
  - 登录账号、登录密码
  - 区域编码/区域名称
  - 状态：正常
点击保存 → 系统自动创建分销商账号（sys_user 中 account_type = 'DISTRIBUTOR_ADMIN'）
```

## 2. 创建商家

```
路径：商家管理 → 新增商家
填写：
  - 商家名称、联系人、联系电话
  - 所属分销商（从下拉列表选择）
  - 抽成比例（如 10.00 表示平台抽成 10%）
  - 地址、营业时间
点击保存 → 商家状态为"待审核"
```

## 3. 审核商家

```
路径：商家管理 → 商家列表 → 点击商家ID → 进入详情
操作：
  - 查看商家资料
  - 点击"审核通过" → 商家状态变为"正常"
  - 商家端员工才能登录
```

## 4. 配置商家小程序

```
路径：商家管理 → 编辑商家 → 小程序配置
填写：
  - C端 AppID：该商家的C端微信小程序 AppID
  - C端 AppSecret：C端小程序 Secret
  - 商家端 AppID：该商家的商家端小程序 AppID
  - 商家端 AppSecret：商家端小程序 Secret
  - 微信商户号：平台微信商户号
  - 微信支付 API 密钥：V3 密钥
注意：密钥字段只显示"已配置/未配置"，不会明文显示。
```

## 5. 上传商品图片

```
路径：团购管理 → 新增团购 → 上传图片
支持格式：jpg/png/webp
大小限制：10MB
```

## 6. 查看订单

```
路径：订单管理 → 全部订单
搜索条件：订单号、商家名称、用户名称、状态、时间范围
操作：查看详情、退款处理
```

## 7. 处理商家结算

```
路径：财务中心 → 商家结算
操作：
  - 查看待结算列表（WAITING_T1）
  - 勾选 → 批量发起打款 → 状态变为 TRANSFERRING
  - 微信回调后 → 状态变为 ARRIVED
  - 失败 → 状态变为 FAILED
```

## 8. 处理分销商结算

```
路径：财务中心 → 分销商结算
操作：同商家结算，但结算周期为每周一
```

## 9. 查看平台转账记录

```
路径：财务中心 → 平台转账记录
列表：转账单号、目标类型(商家/分销商)、金额、状态、微信批次号
```
