# 02 账号权限矩阵

> ⚠️ 这是 DeepSeek 权限越权审核的基准文档。所有角色的数据范围以此为准。

## 角色总览

| 角色 | accountType | 登录入口 | 说明 |
|------|-------------|---------|------|
| 超级管理员 | SUPER_ADMIN | 运营后台 | 全平台管理，可切换分销商视角 |
| 分销商管理员 | DISTRIBUTOR_ADMIN | 运营后台 | 管理名下商家数据 |
| 商家管理员 | MERCHANT_ADMIN | 运营后台 | 管理自己商家 |
| 商家员工 | MERCHANT_STAFF | 运营后台 | 有限权限管理自己商家 |
| 店长 | — (商家端JWT) | 商家端小程序 | 全部9项权限 |
| 店员 | — (商家端JWT) | 商家端小程序 | 订单+核销+统计 |
| C 端用户 | — (小程序JWT) | C 端小程序 | 浏览、下单、支付 |

## ⚠️ 审计发现：当前代码与权限矩阵的差距

以下问题已在 `代码审计问题台账.md` 中详细记录：

| # | 问题 | 影响 |
|---|------|------|
| P0-1 | 后台商家详情 `getInfo` 无归属校验 | 分销商可越权查看其他分销商名下商家详情 |
| P0-2 | 后台分销商详情 `getInfo` 无归属校验 | 分销商可越权查看其他分销商资料 |
| P0-3 | C端商家列表无 AppID 过滤 | C端可能展示非当前 AppID 的商家 |
| P1-1 | 多个后台详情接口无 `@DataScopeBiz` | 列表接口有隔离，详情接口无隔离 |
| P1-7 | `WxMerchantController.home()` 未用 Header 上下文 | URL 参数可被篡改 |

> 以上问题已在台账中标记修复优先级，详见 `代码审计问题台账.md`。

## 1. 超级管理员（平台视角）

| 模块 | 可见范围 | 可操作 |
|------|---------|--------|
| 分销商管理 | 全部分销商 | 增/删/改/查/切换视角/重置密码 |
| 商家管理 | 全部商家 | 增/删/改/查/审核 |
| 商品/团购 | 全部商品 | 查 |
| 订单管理 | 全部订单 | 查/退款处理 |
| 结算管理 | 全部商家结算 + 分销商结算 | 查/发起打款/确认到账 |
| 平台财务 | 全平台流水/收入/转账记录 | 查 |
| 系统管理 | 全部 | 角色/权限/用户/菜单 |
| 分销商切换 | 可切换任意分销商视角 | 切换/返回 |

## 2. 超级管理员（切换分销商视角后）

| 模块 | 可见范围 | 可操作 |
|------|---------|--------|
| 商家管理 | 仅该分销商名下商家 | 查（不能增删改） |
| 商品/团购 | 仅该分销商名下商家的商品 | 查 |
| 订单管理 | 仅该分销商名下商家的订单 | 查 |
| 结算管理 | 仅该分销商名下商家结算 | 查 |
| 分销商佣金 | 仅该分销商的佣金 | 查 |
| 分销商列表 | 不可见 | — |
| 平台总账 | 不可见 | — |
| 系统管理 | 不可见 | — |
| **返回平台视角** | 必须有按钮 | 点击返回 |
