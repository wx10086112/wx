# 04 商家端操作手册

> 写给商家/店员使用商家端小程序的指南。

---

## 1. 登录

```
1. 打开商家端微信小程序
2. 输入账号密码（由运营后台创建）
3. 点击登录 → 进入工作台
```

## 2. 工作台概览

```
登录后默认进入工作台，可看到：
  - 今日销售额
  - 待核销订单数
  - 已完成订单数
  - 退款中订单数
  - 在售套餐数
  - 最新待核销订单列表
```

## 3. 商品管理

### 新增商品
```
路径：商品 → 右上角"新增"
填写：
  - 套餐名称（必填）
  - 套餐描述
  - 套餐图片（上传）
  - 团购价（必填）
  - 原价
  - 库存
  - 有效期（购买后X天内有效）
点击保存 → 商品默认为"下架"状态
```

### 上架/下架商品
```
路径：商品列表 → 点击商品 → 上架/下架
上架后C端用户才能看到该商品
```

### 编辑商品
```
路径：商品列表 → 点击商品 → 编辑
可修改价格、库存、图片等
```

## 4. 核销订单

### 扫码核销
```
路径：核销 → 扫码
扫描用户出示的核销码 → 核销成功
```

### 手动核销
```
路径：核销 → 输入核销码
输入用户提供的核销码（如 LY8012）→ 核销成功
```

### 核销记录
```
路径：核销 → 核销记录
查看历史核销记录
```

## 5. 订单管理

```
路径：订单 → 查看订单列表
筛选：全部/待核销/已完成/退款中
操作：
  - 查看订单详情
  - 核销（从订单列表进入核销）
  - 退款处理（同意/拒绝）
```

## 6. 结算中心

```
路径：我的 → 结算中心
查看内容：
  - 今日收益
  - 本月收益
  - 待到账金额（T+1 自动打款）
  - 已到账金额
  - 平台佣金
  - 结算账户信息
  - 到账记录列表
  - 订单结算流水
注意：商家无需手动提现，系统 T+1 自动结算
```

## 7. 门店设置

```
路径：我的 → 门店设置
可修改：门店名称、联系电话、地址、营业时间
```

## 8. 员工管理

```
路径：我的 → 员工管理（仅店长可见）
操作：添加员工/编辑员工/禁用员工
```
