# 10 数据库关键表说明

---

| 表名 | 说明 | 核心字段 | 数据隔离字段 |
|------|------|---------|-------------|
| `sys_user` | 运营后台用户 | user_id, username, account_type, distributor_id, merchant_id | account_type + distributor_id + merchant_id |
| `distributor` | 分销商信息 | id, name, contact, phone, region_code, status | id |
| `merchant` | 商家主体 | id, name, distributor_id, commission_rate, status, c_mini_app_id, m_mini_app_id | distributor_id |
| `merchant_user` | 商家端员工 | id, merchant_id, username, password, role(owner/member) | merchant_id |
| `merchant_store` | 门店信息 | id, merchant_id, name, address, longitude, latitude | merchant_id |
| `product` | 商品/团购套餐 | id, merchant_id, name, price(元), original_price(元), stock, status | merchant_id |
| `groupon_activity` | 团购活动 | id, merchant_id, name, start_time, end_time, status | merchant_id |
| `mall_order` | 订单主表 | id, order_no, merchant_id, user_id, pay_amount(元), status | merchant_id |
| `order_item` | 订单明细 | id, order_id, merchant_id, product_id, price(元), quantity | merchant_id |
| `payment_record` | 支付记录 | id, order_no, merchant_id, amount(元), pay_status, transaction_id | merchant_id |
| `refund_record` | 退款记录 | id, order_no, merchant_id, refund_amount(元), status | merchant_id |
| `order_profit_ledger` | 三方分账流水 | id, order_no, merchant_id, distributor_id, merchant_amount, platform_amount, distributor_amount, status | merchant_id + distributor_id |
| `merchant_settlement_record` | 商家结算记录 | id, settlement_no, merchant_id, distributor_id, merchant_amount, status(WAITING_T1/TRANSFERRING/ARRIVED/FAILED) | merchant_id + distributor_id |
| `distributor_settlement_record` | 分销商结算记录 | id, settlement_no, distributor_id, merchant_id, amount, status | distributor_id |
| `platform_transfer_record` | 平台转账记录 | id, transfer_no, settlement_no, target_type(merchant/distributor), target_id, amount, status | target_id |
| `merchant_bill` | 商家账单 | id, merchant_id, total_amount, total_commission, net_income, status | merchant_id |
| `transaction_record` | 资金流水 | id, merchant_id, type(payment/withdraw/refund/commission), amount, balance | merchant_id |

> 注意：金额字段统一使用 DECIMAL(10,2) 单位元，接口层乘100转分返回。
