## ⚠️ 审计说明

当前验收标准与代码实际状态存在差距（详见 `代码审计问题台账.md`）：
- P0-1/P0-2：后台详情接口缺少越权防护，权限验收无法通过
- P1-2/P1-3：微信支付为 Stub，支付验收无法通过
- P1-4：微信商家转账为 Stub，结算验收不完整
- 以上问题修复后方可进行完整验收

## 功能验收

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | C端用户登录 | 微信登录获取openId → 签发JWT → 存入用户表 |
| 2 | C端浏览商家 | 按AppID展示对应商家信息、商品列表 |
| 3 | C端下单 | 创建订单 → 订单状态=待支付 |
| 4 | C端支付 | 调起微信支付 → 回调更新状态=已支付 |
| 5 | C端查看核销码 | 已支付订单展示核销码 |
| 6 | 商家端登录 | username+password → 校验BCrypt → 签发JWT |
| 7 | 商家端商品上架 | 新增商品 → 上架 → C端可见 |
| 8 | 商家端核销 | 扫码/手动输入 → 订单状态=已完成 |
| 9 | 商家端结算中心 | 展示今日/本月收益、待到账、已到账、流水 |

## 权限验收

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | 超级管理员全平台 | 可看所有分销商/商家/订单/结算 |
| 2 | 切换分销商视角 | 数据范围收窄为该分销商名下 |
| 3 | 返回平台视角 | 恢复全平台数据 |
| 4 | 分销商隔离 | 只能看自己名下商家 |
| 5 | 商家隔离 | 只能看自己商家数据 |
| 6 | C端隔离 | 只看当前AppID对应商家 |
| 7 | 越权访问 | 返回403或空数据 |

## 支付验收

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | 支付创建 | 返回微信支付参数 |
| 2 | 支付回调 | 验签 → 更新订单状态 |
| 3 | 支付幂等 | 同一回调多次 → 订单状态不变 |
| 4 | Stub模式 | dev环境可用，生产返回错误提示 |

## 结算验收

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | 核销后生成分账 | order_profit_ledger 记录存在 |
| 2 | 商家结算记录 | merchant_settlement_record 状态=WAITING_T1 |
| 3 | 分账精度 | merchantAmt + platformFee == payAmount |
| 4 | 打款流程 | TRANSFERRING → ARRIVED/FAILED |
| 5 | 退款回滚 | 已到账后退款生成负向记录 |
