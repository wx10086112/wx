# 05 C端用户流程说明

> 消费者使用 C 端小程序的完整流程。

---

## 1. 首次使用

```
1. 用户打开 C 端微信小程序
2. 进入首页 → 看到商家信息和团购列表
3. 浏览商家 → 查看商家详情、商品/团购列表
```

## 2. 登录/注册

```
1. 用户在"我的"页面点击登录
2. 微信授权 → 后端获取 openId
3. 自动注册（首次登录）或直接登录（非首次）
4. 返回 JWT token → 存入本地缓存
5. 自动绑定手机号（可选）
```

## 3. 浏览商品

```
1. 首页 → 查看推荐团购
2. 搜索 → 输入关键词 → 搜索商品
3. 商家详情 → 查看该商家全部在售商品
4. 商品详情 → 查看价格、描述、有效期
```

## 4. 购买流程

```
1. 商品详情页 → 点击"立即购买"
2. 选择数量 → 进入结算页
3. 确认订单信息 → 选择优惠券（如有）
4. 点击"提交订单" → 弹出微信支付
5. 输入密码 → 支付成功
6. 跳转到订单详情 → 展示核销码
```

## 5. 到店核销

```
1. 用户到店 → 打开订单详情
2. 出示核销码（二维码/数字码）
3. 商家扫码或输入核销码
4. 核销成功 → 订单状态变为"已完成"
```

## 6. 退款

```
1. 用户在我的订单中找到已支付的订单
2. 点击"申请退款"
3. 商家审核 → 同意/拒绝
4. 商家同意 → 退款到用户微信
5. 订单状态变为"已退款"
```

## 7. 我的页面

```
"我的"页面包含：
  - 个人信息（头像、昵称、手机号）
  - 全部订单（待支付/待使用/已完成/退款）
  - 优惠券
  - 收藏
  - 联系客服
```
