## ⚠️ 审计发现的接口问题

| 问题 | 说明 |
|------|------|
| 订单详情接口 | 前端显示字段错误：商品名称显示 orderNo、商家名称显示 merchantId（台账 P1-11） |
| 提现拒绝接口 | 前端传 `status=0` 而非 `status=3`，拒绝原因未传递（台账 P1-12） |
| 批量转账接口 | `PlatformTransferServiceImpl` 事务自调用失效（台账 P1-13） |
| 客户端过滤 | merchant/list、merchant/flow、merchant/withdraw 搜索在客户端执行，分页实效（台账 P2-11） |
| Controller 直接调用 Mapper | `MallOrderExtendController`、`MallFinanceExtendController` 绕过 Service 层（台账 P0-4） |
