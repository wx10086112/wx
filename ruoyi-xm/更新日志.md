### 三、核销码体系设计

#### 3.1 核销码生成规则

**格式**：`LY{日期8位}{序列号4位}`

**示例**：`LY202605250001`

| 部分 | 说明 | 示例 |
|------|------|------|
| LY | 固定前缀（零点科技团购） | LY |
| 20260525 | 支付日期（8位） | 20260525 |
| 0001 | 当日序列号（4位，Redis原子自增） | 0001 |

**特点**：
- 唯一性：日期+Redis原子自增，不可能重复
- 不可预测：序列号连续但无规律可循
- 可读性：客服可直接读出"LY二零二六零五二五零零零一"
- 可追溯：前8位直接知道支付日期

#### 3.2 Java生成代码

```java
@Service
public class WriteOffCodeGenerator {

    @Resource
    private StringRedisTemplate stringRedisTemplate;

    private static final String CODE_PREFIX = "LY";
    private static final String REDIS_KEY_PREFIX = "write_off:code:seq:";
    private static final int CODE_LENGTH = 4; // 序列号位数

    /**
     * 生成核销码
     * 格式: LY202605250001
     */
    public String generate() {
        String dateStr = new SimpleDateFormat("yyyyMMdd").format(new Date());
        String redisKey = REDIS_KEY_PREFIX + dateStr;

        // Redis原子自增，当日首次从1开始
        Long seq = stringRedisTemplate.opsForValue().increment(redisKey);

        // 设置过期时间（2天后自动清理，防内存泄漏）
        if (seq != null && seq == 1) {
            stringRedisTemplate.expire(redisKey, 2, TimeUnit.DAYS);
        }

        // 格式化为4位数字，左补零
        String seqStr = String.format("%0" + CODE_LENGTH + "d", seq);

        return CODE_PREFIX + dateStr + seqStr;
    }

    /**
     * 校验核销码格式
     */
    public boolean isValid(String code) {
        if (code == null || code.length() != 14) {
            return false;
        }
        if (!code.startsWith(CODE_PREFIX)) {
            return false;
        }
        // 日期部分必须是数字
        String datePart = code.substring(2, 10);
        String seqPart = code.substring(10);
        return datePart.matches("\\d{8}") && seqPart.matches("\\d{4}");
    }
}
```

#### 3.3 Redis防重复方案

```
Redis Key: write_off:code:seq:20260525
Value: 原子自增整数
TTL: 2天（自动过期清理）
```

**流程**：
1. 支付成功时调用 `generate()`
2. Redis `INCR write_off:code:seq:20260525` → 返回序列号
3. 如果返回1（当天首个），设置 `EXPIRE` 2天
4. 拼接 `LY + 日期 + 序列号` 返回

**高并发保障**：
- Redis INCR 是原子操作，10000并发也保证不重复
- 每天独立序列，跨天自动从1开始
- 2天TTL自动清理历史数据

#### 4.2 订单状态机

```
                    ┌─────────────┐
                    │  0 待支付    │
                    └──────┬──────┘
                           │ 用户支付成功
                           ↓
                    ┌─────────────┐
                    │  1 已支付    │  ← 生成核销码 writeOffCode
                    │  (待核销)    │     writeOffStatus = 0
                    └──────┬──────┘
                    │      │
          用户申请退款     │ 商家扫码核销
                    ↓      ↓
            ┌──────────┐  ┌─────────────┐
            │ 4 已退款   │  │ 3 已完成     │  writeOffStatus = 1
            └──────────┘  │  (已核销)    │  writeOffTime = 当前时间
                          └─────────────┘
```

**状态值定义：**

| 状态值 | 名称 | 说明 |
|--------|------|------|
| 0 | 待支付 | 用户下单未支付 |
| 1 | 已支付 | 支付成功，待核销 |
| 3 | 已完成 | 商家已核销 |
| 4 | 已退款 | 用户申请退款 |

**核销前置校验：**
1. 订单是否存在
2. 订单状态是否为 1（已支付）
3. write_off_code 是否与传入的 code 匹配
4. write_off_status 是否为 0（未核销）
5. 订单商家ID 是否与当前操作员的商家ID匹配
6. 商品是否已过期（valid_days）

**接口地址**：`POST /wxmini/common/upload`

**请求参数**：

**返回结构**：
```json

  "msg": "操作成功",
  "data": {
    "url": "/profile/merchant/1/product/100/main/a1b2c3d4.jpg",
    "fileName": "a1b2c3d4.jpg",
    "imageType": "main"
  }

```

**Controller 实现**：

```java
@RestController
@RequestMapping("/wxmini/common")
public class WxMiniUploadController {

    @Value("${ruoyi.profile}")
    private String profilePath;

    @Resource
    private IProductImageService productImageService;

    @PostMapping("/upload")
    public AjaxResult upload(
            @RequestParam("file") MultipartFile file,
            @RequestParam("merchantId") Long merchantId,
            @RequestParam(value = "productId", required = false) Long productId,
            @RequestParam(value = "imageType", required = false, defaultValue = "main") String imageType) {

        if (file == null || file.isEmpty()) {
            return AjaxResult.error("请选择要上传的文件");
        }

        // 校验文件大小（10MB）
        if (file.getSize() > 10 * 1024 * 1024) {
            return AjaxResult.error("文件大小不能超过10MB");
        }

        // 校验文件类型
        String originalName = file.getOriginalFilename();
        String ext = getExtension(originalName);
        if (!isImageExtension(ext)) {
            return AjaxResult.error("仅支持jpg/png/gif格式");
        }

        try {
            // 构建目录: merchant/{merchantId}/{type}/
            // 或: merchant/{merchantId}/product/{productId}/{type}/
            StringBuilder dirBuilder = new StringBuilder("merchant/");
            dirBuilder.append(merchantId).append("/");

            if (productId != null) {
                dirBuilder.append("product/").append(productId).append("/");
            }
            dirBuilder.append(imageType).append("/");

            String subDir = dirBuilder.toString();
            File dir = new File(profilePath, subDir);
            if (!dir.exists()) {
                dir.mkdirs();
            }

            // 生成文件名: {type}_{uuid8}.jpg
            String uuid = UUID.randomUUID().toString().replace("-", "").substring(0, 8);
            String fileName = imageType + "_" + uuid + "." + ext;
            String relativePath = subDir + fileName;

            // 保存文件
            File dest = new File(profilePath, relativePath);
            file.transferTo(dest);

            String url = "/profile/" + relativePath;

            // 如果传了productId，写入product_image表
            if (productId != null) {
                ProductImage image = new ProductImage();
                image.setProductId(productId);
                image.setMerchantId(merchantId);
                image.setImageType(imageType);
                image.setImageUrl(url);
                image.setStatus(1);
                productImageService.insertProductImage(image);
            }

            Map<String, Object> result = new HashMap<>();
            result.put("url", url);
            result.put("fileName", fileName);
            result.put("imageType", imageType);
            return AjaxResult.success(result);

        } catch (IOException e) {
            return AjaxResult.error("文件上传失败: " + e.getMessage());
        }
    }

    private boolean isImageExtension(String ext) {
        return "jpg".equalsIgnoreCase(ext) || "jpeg".equalsIgnoreCase(ext)
            || "png".equalsIgnoreCase(ext) || "gif".equalsIgnoreCase(ext);
    }

    private String getExtension(String fileName) {
        if (fileName == null || !fileName.contains(".")) {
            return "jpg";
        }
        return fileName.substring(fileName.lastIndexOf(".") + 1);
    }
}
```

**Service 实现**：

```java
@Service
public class WriteOffServiceImpl implements IWriteOffService {

    @Resource
    private MallOrderMapper orderMapper;
    @Resource
    private WriteOffRecordMapper writeOffRecordMapper;
    @Resource
    private WriteOffCodeGenerator codeGenerator;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public WriteOffResultVO writeOff(String code, Long merchantId,
                                      Long operatorId, String operatorName) {
        // 1. 校验核销码格式
        if (!codeGenerator.isValid(code)) {
            throw new BusinessException("核销码格式不正确");
        }

        // 2. 查询订单
        MallOrder order = orderMapper.selectOrderByWriteOffCode(code);
        if (order == null) {
            throw new BusinessException("核销码不存在");
        }

        // 3. 校验商家归属
        if (!order.getMerchantId().equals(merchantId)) {
            throw new BusinessException("该订单不属于当前商家");
        }

        // 4. 校验订单状态
        if (order.getStatus() != 1) {
            throw new BusinessException("订单状态异常，无法核销");
        }

        // 5. 校验是否已核销
        if (order.getWriteOffStatus() != null && order.getWriteOffStatus() == 1) {
            throw new BusinessException("该订单已核销，请勿重复操作");
        }

        // 6. 校验是否过期（商品有效天数）
        if (order.getPayTime() != null && order.getValidDays() != null && order.getValidDays() > 0) {
            Date expireTime = DateUtils.addDays(order.getPayTime(), order.getValidDays());
            if (new Date().after(expireTime)) {
                throw new BusinessException("该订单已过期，无法核销");
            }
        }

        // 7. 更新订单状态
        order.setWriteOffStatus(1);
        order.setWriteOffTime(new Date());
        order.setWriteOffUserId(operatorId);
        order.setStatus(3); // 已完成
        order.setUseTime(new Date());
        orderMapper.updateMallOrder(order);

        // 8. 写入核销记录
        WriteOffRecord record = new WriteOffRecord();
        record.setOrderId(order.getId());
        record.setOrderNo(order.getOrderNo());
        record.setWriteOffCode(code);
        record.setMerchantId(merchantId);
        record.setStoreId(order.getStoreId());
        record.setOperatorId(operatorId);
        record.setOperatorName(operatorName);
        record.setWriteOffType(1); // 扫码核销
        record.setWriteOffTime(new Date());
        record.setProductName(order.getProductName());
        record.setProductAmount(order.getPayAmount());
        record.setStatus(1);
        writeOffRecordMapper.insertWriteOffRecord(record);

        // 9. 返回结果
        WriteOffResultVO vo = new WriteOffResultVO();
        vo.setOrderNo(order.getOrderNo());
        vo.setProductName(order.getProductName());
        vo.setPayAmount(order.getPayAmount());
        vo.setWriteOffTime(record.getWriteOffTime());
        vo.setOperatorName(operatorName);
        return vo;
    }
}
```
