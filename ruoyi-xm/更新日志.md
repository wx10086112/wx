## 2026-05-19 多租户小程序架构（每个商家独立AppID）

### 架构说明
- 每个商家拥有2个独立微信小程序：C端（用户下单）+ 商家端（管理/核销）
- 一个后端服务所有商家，通过 AppID→merchantId 映射隔离数据
- C端登录：前端传 AppId + code → 后端按 AppId 查商家 → 用该商家的 secret 调微信
- 商家端登录：用户名密码登录（JWT含merchantId），不走微信SDK
- 用户体系：每个小程序的用户完全独立（Option A），openId不同小程序互不关联

### 数据库变更
- `merchant` 表新增字段：c_mini_app_id, c_mini_app_secret, m_mini_app_id, m_mini_app_secret, wx_pay_mch_id, wx_pay_api_key
- c_mini_app_id 和 m_mini_app_id 加唯一索引
- SQL脚本：`ruoyi-vue-wxmini-main/project-docs/test-sql/03_multi_tenant_miniapp.sql`

### 登录流程
```
C端：wx.login() → wx.getAccountInfoSync().miniProgram.appId → POST /wxmini/login?appid=xxx&code=yyy
→ WxLoginController → WxMaServiceManager.getService(appid) → DB查merchant表加载secret
→ wxMaService.getUserService().getSessionInfo(code) → openid → 查mall_user → token

商家端：POST /wxmini/merchant-mini/auth/login {username: xxx}
→ MerchantMiniServiceImpl → 查merchant_user → JWT(含merchantId)
```

### 微信消息推送
每个商家配置独立verifyUrl：`https://domain.com/wxmini/portal/{c_mini_app_id}`
- GET: 微信服务器验证签名
- POST: 接收消息推送（当前无实际处理逻辑，预留）

## 2026-05-18 后端接口异常修复

### 修复问题
1. `MallOrderMapper.xml`：`countOrderByMerchantIdAndStatus` 错误使用 `resultMap="MallOrderResult"` 改为 `resultType="int"`（count查询不能用实体映射）
2. `DashboardServiceImpl.selectTrendData()`：`row.get("date")` 返回 `java.sql.Date` 不能强转为 `String`，改用 `SimpleDateFormat.format()` 兼容；同时修正字段名 `count`→`orderCount`、`amount`→`totalAmount`，移除不存在的 `completedCount` 引用
3. `MallOrderMapper.selectOrderStatsByStatus()`：SQL别名 `AS count` 改为 `AS cnt`，与 DashboardServiceImpl 读取 `row.get("cnt")` 匹配
4. `MallOrderMapper`：`selectSalesStats`/`sumTodayAmount`/`sumTotalFlow` 的 `NOT IN (0, 6)` 改为 `NOT IN (0, 5)`（数据库状态最大值为5，6不存在）
5. `MallDashboardExtendController.salesStats()`：SQL返回 `totalAmount` 而非 `totalSales`，修正字段名；`avgOrderAmount` 改为代码计算（总金额/总订单数）而非读取不存在的字段
6. `MallDashboardExtendController`：新增 `/order-status` 和 `/hot-products` 两个缺失端点，前端 dashboard 首页调用这两个接口
7. `ProductMapper.selectHotProducts()`：`m.merchant_name` 改为 `m.name AS merchant_name`（merchant 表字段名为 name）
8. `TransactionRecordMapper.xml`：`transaction_record` 表无 `update_time`/`remark` 列，从 SELECT/INSERT/resultMap 中移除
9. `PlatformIncomeMapper.xml`：`platform_income` 表无 `update_time`/`remark` 列，从 SELECT/INSERT/resultMap 中移除

| 商品列表 | product | 按商家ID查询，状态过滤(上架/下架) |
| 商品管理 | product | 新增/更新商品，上下架操作 |
